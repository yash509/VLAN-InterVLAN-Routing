# VLAN + Inter-VLAN Routing

This repository documents the step-by-step process of configuring VLANs and enabling inter-VLAN routing using Cisco Packet Tracer.

---

## ⚙️ Topology
- Cisco 2960 Switch
- Cisco 2911 Router
- 4 PCs (IT, HR, Finance, Operations)

---

## PCs Configuration by assigning static IPs:

- VLAN 10 (IT): 192.168.10.2 / 255.255.255.0, GW 192.168.10.1
- VLAN 20 (HR): 192.168.20.2 / 255.255.255.0, GW 192.168.20.1
- VLAN 30 (Finance): 192.168.30.2 / 255.255.255.0, GW 192.168.30.1
- VLAN 40 (Operations): 192.168.40.2 / 255.255.255.0, GW 192.168.40.1
